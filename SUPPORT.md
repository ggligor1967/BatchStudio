# Support

## Self-service

Start with [Installation](docs/INSTALLATION.md), [User guide](docs/USER_GUIDE.md), and [Troubleshooting](docs/TROUBLESHOOTING.md). OCR-specific setup is in [OCR](docs/OCR.md), and known product boundaries are in [Limitations](docs/LIMITATIONS.md).

## Asking for help

Search existing [GitHub Issues](https://github.com/ggligor1967/BatchStudio/issues) before opening a new one. Include:

- BatchStudio version and installation method;
- Python and operating-system versions;
- the operation IDs and non-sensitive configuration used;
- input type, observed result, and complete error text;
- the smallest reproducible example that contains no private data.

Do not attach confidential source documents. Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

The project does not currently publish guaranteed response times or commercial support commitments.
